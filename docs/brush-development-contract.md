# Immutable tiled brush and eraser

> Export note: Recorded validation results are historical source-repository observations, not qualification of this standalone repository. Commands use the standalone layout.

`brushStroke(document, target, store, points, settings, stop)` returns one worker-owned transaction. The UI publishes a successful stroke as one history entry. A thrown error or cancellation returns no transaction; source documents, read leases and existing history stay immutable. Empty paths, zero opacity, off-raster paths, and strokes whose packed output equals their input return a no-op, preserving redo.

The software dab behavior adapts `Compositor/Document/BrushStroke.swift`: spacing is `max(0.25, diameter × 0.015)` for hard tips and `max(0.25, diameter × 0.025)` for soft tips. Hard dabs union their coverage; soft dabs accumulate screen coverage `1 - (1 - old) × (1 - dab)`. Soft falloff uses the normalized Gaussian with exponent coefficient 2.5. Every tile is composed once from its original immutable pixels and accumulated coverage multiplied by stroke opacity. Overlapping dabs therefore never exceed the whole-stroke opacity cap. The returned canonical pixels remain RGBA16F; admitted temporary arithmetic uses FP32 and never narrows to RGBA8.

Brush diameter and points are document-space units. The inverse affine determines conservative source tile intersections; each source subpixel is mapped directly through the layer's document affine. A 2×2 footprint integration antialiases hard edges and supports rotation, flips, and nonuniform scale. Rectangle/ellipse/inverted selections use the shared 8×8 source-footprint coverage in document coordinates, clipped to the canvas, including inverted selections. The existing immutable raster extent bounds this first implementation; it does not grow a layer or mask past its extent. Input points form a polyline; spline interpolation, smoothing, pressure variation, healing and clone tools are separate work.

Painting uses straight encoded sRGB foreground converted into premultiplied linear working color, then source-over with accumulated coverage. Erasing scales all premultiplied channels and alpha together and reaches canonical transparent zero. Mask painting uses the encoded foreground red component as grayscale coverage, stored as zero RGB plus alpha in the `mask-rgba16f-le` contract. Masks follow the linked layer affine. Disabled masks and effectively hidden layers refuse paint. Shared mask assets fork identity when painted, so immutable duplicated layers retain their original mask.

Settings admit diameter 1–4096, hardness/opacity 0–1, and at most 8192 finite points bounded to ±1,000,000. Expansion is additionally bounded to 262,144 software dabs; an exceptionally long/dense stroke exceeding that bound is rejected before allocation. Dab storage is admitted before allocation. Per-tile FP32 output and coverage are admitted together, and only one original read lease is held during composition. Each read propagates the job stop token into disk rehydration. Cancellation is checked during path expansion, before tiles, and at each dab row. Caller input paths and immutable graph/container metadata need the caller's job allowance. There is no hard kernel IO cancellation deadline.

`brush_test.cpp` covers hard/soft overlap and opacity caps, premultiplied erasure, one-entry undo/redo and no-op redo preservation, transformed diameter, rectangle and inverted ellipse clipping, mask paint/history, bounded argument/cancellation rejection, and editing verified disk-backed source pixels without mutating the original version. Tests use tiny 16×16 assets and an explicit private disk fixture. Parent owns CMake registration and serial compilation/execution; no test pass is claimed by this author.
